# Changelog

All notable changes to the _Spacewar!_ Critical Code Studies website. Versions follow the GitHub releases.

## v1.1.0 — 2026-06-10

- Brand assets for link previews: `assets/og-card.png` (Open Graph card), `assets/social-preview.png` (repo social card, 1280×640), `assets/org-avatar.png` (organisation mark).
- Open Graph / Twitter metadata across all pages, so shared links preview with the CRT card instead of a generic icon.
- Wikipedia deep-links for named entities in the facts cards.
- Fixed in-page anchor jumps so the sticky header no longer covers the target heading.
- Bibliography curation against Zotero (additions, removals, corrected references).
- `CONTRIBUTING.md` and the protected-`main` / pull-request workflow.
- Dates normalised to 1962 on the front page.

## v1.0.0 — 2026-06-09

- Initial project front door: landing page situating the reading in Critical Code Studies, with the _Inventing ELIZA_ companion framing, a short history of _Spacewar!_, the source object, a hardware/facts panel, the reading method, and contacts.
- `play.html`: the original 1962 source running on a PDP-1 emulator.
- `bibliography.html`: the Critical Code Studies bibliography in site style.
- DEC PDP-1 Type 30 CRT aesthetic (phosphor on black, scanlines, vector hero starfield).
