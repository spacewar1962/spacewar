# Code

Working space for programming as scholarship. This is where experimental code lives: interventions made on _Spacewar!_ as part of the reading, kept separate from the original artefact so the source at the repository root stays untouched and citable.

Following the method set out in _10 PRINT_, interventions fall into four kinds. Each should sit in its own subfolder with a short `README.md` recording what was changed and what the change revealed.

- **Modifications** — small variations in the original parameters, to make arbitrary conventions visible by contrast.
- **Variations** — systematic exploration of alternatives, to test what is essential and what is contingent.
- **Elaborations** — extensions that explore what the minimal program enables when developed.
- **Ports** — translations to other platforms or languages, where questions of fidelity and improvement come to the surface.

This folder is for future use; it is empty for now apart from this note.
