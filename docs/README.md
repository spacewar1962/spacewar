# Reading notes

Public-facing notes for the critical code reading of _Spacewar!_. This is where the analysis is worked through in the open, distinct from the monograph drafting and from any private working notes.

## Contents

- [`reading-log.md`](reading-log.md) — a dated, reverse-chronological log of reading sessions: what was looked at, what was found, what it opened.
- [`readings/`](readings/) — close-reading memos, one per code fragment, each keyed to a line range in [`spacewar.mac`](../spacewar.mac) and the corresponding octal block in [`spacewar.lst`](../spacewar.lst).

## Method

Each memo follows the two-part case-study form of Critical Code Studies: first a technical explication that renders the fragment legible, then an interpretive analysis of its extra-functional significance, spiralling outward to the cultural constellation it opens. Keep code excerpts generous so others can read against the claim. Any reference is verified against Zotero before it enters a draft.

## Contributing

Propose a thread by opening a **Reading note or idea** issue, or add a memo directly through a pull request (see [`CONTRIBUTING.md`](../CONTRIBUTING.md)).
