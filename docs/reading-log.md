# Reading log

A running, reverse-chronological log of the reading. Newest entries on top. Each entry records what was looked at, what was found, and what it opened. Fuller close readings live as memos in [`readings/`](readings/).

## Entry template

```
## YYYY-MM-DD: short title

**Looked at:** spacewar.mac L<start>–L<end> (and/or feature, paratext)
**Found:** the observation.
**Opens:** the thread, question, or constellation it leads to. Link a memo with [readings/<slug>.md](readings/<slug>.md).
```
