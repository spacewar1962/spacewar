SPACEWAR!

Reading the code at the origin of computational play
▶ Play Bibliography

The argument

Spacewar! is where code first becomes play. Written across 1961-62 by Steve Russell and a circle of MIT hackers for the DEC PDP-1, in roughly two thousand words of MIDAS macro-assembly it gave the computer a starfield, two ships, gravity, and a panic button. This project reads that program as a cultural text, in the tradition of Critical Code Studies: at once literature, mechanism, spatial form, and a repository of the social formation that produced it.

The object

  • spacewar.lst: assembler listing, octal addresses + machine words

The machine

1962 · 18-bit words · 4096 words of core · Type 30 CRT at 1024 x 1024 points, P7 phosphor · PDP-1 ~$120,000. The Type 30 was a point-plotting vector display derived from radar. This page is rendered in its spirit.
