Your details

Initials and a date are attached to every annotation, so discussions can be followed. They are kept in this browser.

Shared annotations

Annotations are shared through a private Hypothesis group. Paste the group's link (hypothes.is/groups/ID/…) or just its ID, and a personal API token (hypothes.is/account/developer). Without them, notes are kept as drafts in this browser and can be exported or published later.

Reading code

Applies wherever code is shown: listings, comparisons, traces, tables. The A− and A+ buttons in the top bar change the size too.

Figures

The background given to exported figures (PNG and SVG). On a white or paper background figures are drawn in dark ink; on black, in phosphor. Transparent leaves the background empty, for layering in other software.

Spacewar! Research Bench

AuthorDavid M. Berry
Version
Released
PurposeA working bench for the critical reading of the Spacewar! source code (1961 to 1963 and after), made for the Spacewar! book project: assemble and run each version, compare them, trace their genealogy, annotate together, and export for writing.
Tech stackStatic HTML, CSS and plain JavaScript: no framework, no libraries, no build step. Served from GitHub Pages and run entirely in the browser; the sources and tape images are read from the repository’s sources/ folder as they are needed. Word files are written directly as Office Open XML (zipped in the browser), figures as SVG and, through the canvas, PNG. The optional code fonts come from Google Fonts. Shared notes go through the Hypothesis API; settings, drafts and the tray are kept in the browser’s local storage.
InsideA JavaScript port of the macro1 cross-assembler from the SIMH project, with the 1962–63 MACRO rules the tapes show; a PDP-1 emulator with the Type 30 display; FIO-DEC tape reading; shared notes through Hypothesis.
SourcesThe program by Steve Russell, Peter Samson, Dan Edwards, Martin Graetz, Alan Kotok and others at MIT; later versions by Monty Preonas (“ddp”), “dfw” and Joe Morris; tapes from Steve Russell’s box (bitsavers); transcriptions and reconstructions by Norbert Landsteiner and the Computer History Museum. Each version’s sources and provenance are under Version & notes.
