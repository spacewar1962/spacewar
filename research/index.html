Site map

Annotations

Twelve stops through reading, running, comparing and annotating; about three minutes.

Your details

Initials and a date are attached to every annotation, so discussions can be followed. They are kept in this browser.

Shared annotations

Annotations are shared through a private Hypothesis group. Paste the group's link (hypothes.is/groups/ID/…) or just its ID, and a personal API token (hypothes.is/account/developer). Without them, annotations are kept as drafts in this browser and can be exported or published later.

Colour theme

The colours of the whole bench: listings, annotations, figures and tapes. The ◐ button in the top bar switches between your last light and dark themes. The scope in Run keeps the PDP-1’s own phosphor.

Reading code

Applies wherever code is shown: listings, comparisons, traces, tables. The A− and A+ buttons in the top bar change the size too.

Figures

The background given to exported figures (PNG and SVG). On a white or paper background figures are drawn in dark ink; on black, in phosphor. Transparent leaves the background empty, for layering in other software.

Annotate

Unsaved annotation. Save it, or Cancel to discard it.

Spacewar! Research Bench

AuthorDavid M. Berry
Version
Released
PurposeA bench for the critical reading of the Spacewar! source code, made for the Spacewar! book project.
Tech stackPlain HTML, CSS and JavaScript; no framework or build step. Runs in the browser from GitHub Pages; annotations via Hypothesis; settings and drafts in local storage; My notes in local storage and kept privately on Hypothesis; Help ▸ Back up everything saves all of it to one file.
InsideThe macro1 assembler (from SIMH) with the 1962–63 MACRO rules; a PDP-1 emulator with the Type 30 display; a FIO-DEC tape reader.
SourcesCode by Russell, Samson, Edwards, Graetz, Kotok and others at MIT; later versions by Preonas (“ddp”), “dfw” and Morris; tapes from Russell’s box (bitsavers); transcriptions by Landsteiner and the Computer History Museum. Details under Version.
