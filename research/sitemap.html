Site map

Every view of the Spacewar! Research Bench as a plain link, for when a menu will not open. The bench itself runs in JavaScript: the emulator, the listings and the annotations all need it. Without JavaScript, the source files below open on GitHub.

Each link opens Spacewar! 3.1 unless it names a version; the version picker at the top of the bench changes it. Any view’s address can be shared as it stands.
