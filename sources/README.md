# Source listings

Locally hosted source files for the version history on `code.html`, kept here to
guard against external link-rot.

| File | Version | Provenance |
|------|---------|------------|
| `sw41f.txt` | Spacewar! 4.1f (Computer History Museum) | PDP-1 MACRO source by Peter Samson ("prs"), a 2005 reconstruction on the 4.1 (2/20/63, "dfw") base with the 4.8 score display grafted on; star intensities remapped for the CHM PDP-1; score-display delay tweaked 2008-08-22. Recovered from bitsavers.org `bits/DEC/pdp1/from_peter_samson/sw41f.mac` (saved here as `.txt` so it views in the browser). |
| `sw41f.rim` | Spacewar! 4.1f (Computer History Museum) | The matching RIM-format paper-tape image. From bitsavers.org `bits/DEC/pdp1/from_peter_samson/sw41f.rim`. |

Spacewar! is in the public domain. These files are MIT-era source and reconstructions
preserved by the community.
