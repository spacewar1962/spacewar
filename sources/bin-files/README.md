# Loose paper-tape images

RIM-format PDP-1 paper-tape images and one text file, gathered while surveying the
archives for new versions. `.bin` files are binary tape images (load them in a PDP-1
emulator such as masswerk.at to run).

| File | What it is | New version? |
|------|-----------|--------------|
| `spacewar4.2a_sa4.bin` | The **authentic 4.2a** paper tape (dfw strain, ~22 Feb 1963), from Steve Russell's archive | Authentic tape we lacked |
| `spacewar2B_2apr62.bin` | Spacewar! 2B (2 Apr 1962) binary | No (have 2B) |
| `newSpacewar_4-30-60.bin` | Read-in data matches `spacewar3.1` byte-for-byte (one leader byte apart); almost certainly **Spacewar! 3.1** under a different label, not a new version | No (= 3.1, to confirm in emulator) |
| `spacewar4.8_scorer.txt` | Text of the 4.8 scorer routine | No (have 4.8 scorer) |

Note: PDP-1 `.bin` tapes cannot be read as text without disassembly; identifications
above are by name, provenance, and byte-comparison against known tapes.
