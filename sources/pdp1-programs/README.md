# PDP-1 programs (Spacewar! kin)

Other PDP-1 programs from Peter Samson's collection, mirrored from
bitsavers.org `bits/DEC/pdp1/from_peter_samson/`. These are **not** Spacewar!
versions; they are the surrounding display-hack and music culture of the same
people and the same machine, kept here for context rather than for the version
history. Filenames are left as bitsavers holds them.

`.mac` = PDP-1 MACRO source; `.rim` = RIM-format paper-tape image.

| File | Program | Notes |
|------|---------|-------|
| `dpys5.mac` / `.rim` | Display hacks | A bundle of PDP-1 display hacks, "start at 0 for munching squares." Munching Squares is the canonical early graphics hack, kin to Minsky's display work. Reassembled by Samson, 2005–2008. |
| `hc1d.mac` / `.rim` | Harmony Compiler, phase 1 | Peter Samson's music-notation compiler, dated 21 May 1963; retyped 2006. Compiles a written score into the form the music player reads. |
| `pdp1m13.mac` / `.rim` | PDP-1 Music (player) | Samson's PDP-1 music program, "music 13," with sense-switch controls for detuning and voices. The PDP-1's loudspeaker music for which the Harmony Compiler prepared scores. |
| `lives2.mac` / `.rim` | PDP-1 Lives | A PDP-1 implementation of Conway's Game of Life, revised 2006. |
