/ Spacewar! 4.0TS - normalised source transcription
/ ----------------------------------------------------------------------
/ Transcribed from the scanned listing "spacewar 4.0ts  5/4/63  ddp"
/ (spacewar-4.0ts-4may1963.pdf, 33 pp.), Monty Preonas's ("ddp") "Twin
/ Star" variant of Spacewar! 4.0. Extracted by David M. Berry.
/
/ Per the masswerk genealogy, 4.0TS is version 4.0 with a simplified
/ starfield (4th-magnitude stars removed) and minor hyperspace
/ modifications. The two divergences from 4.0 are confirmed by the scan:
/   (1) the background routine (pt.1, "background" define) makes only
/       THREE dislis calls -- dislis 1j,1q,3 / 2j,2q,2 / 3j,3q,1 -- the
/       "dislis 4j,4q,0" call present in 4.0 is removed; and
/   (2) the starfield data table appended here ("stars by prs for s/w 2b",
/       pp.31-33) likewise omits the 4th-magnitude star group: it carries
/       only 1j/1q, 2j/2q and 3j/3q, not a 4j/4q block.
/   The "minor hyperspace modifications" are visible in the hp1 routine
/   (pt.2, "this routine handles a non-colliding ship invisibly in
/   hyperspace"): after setting the new angle (lac ran / dac i mth),
/   4.0TS does "random / sar 6s / dac i mom", giving the ship a random
/   angular velocity on hyperspace re-entry. The 4.0 listing instead has
/   "setup ~hpt,3" before "lac ran / dac i mth" and closes the hp4 loop
/   with "count ~hpt,hp4" (a fixed spin of the angle), with no random
/   "dac i mom". 4.0TS thus drops the hpt spin loop and randomises mom
/   instead. Otherwise hp1/hp3 are structurally as in 4.0.
/
/ Method: read page by page against the scan images; OCR was used only as
/ a first pass and every numeral and mnemonic was checked by eye. The 4.0
/ listing (spacewar-4.0-2feb1963-(Morris).txt) was used to resolve
/ ambiguous readings of the shared routines, but this is a different
/ version and what the 4.0TS scan actually shows is transcribed.
/ Conventions follow the bitsavers Samson files: "~" marks a variable
/ shown overlined in the original; tabs separate the label, instruction
/ and "/" comment columns.
/
/ Confidence notes:
/   - pt.1 header reads "spacewar 4.0ts  5/4/63  ddp · pt 1".
/   - p.1 carries a definition line, "ioh=xct (nop", that is not present
/     in the 4.0 listing (in 4.0 "ioh" is defined elsewhere); transcribed
/     as it appears, with its "/delay for dpy's" comment.
/   - p.16: "lio ddd / spi i" -- the skip is read as "spi i" (matching the
/     valid PDP-1 form and the 4.0 listing); the scan glyph is ambiguous
/     between "i" and "1".
/   - p.27: 4.0TS prints both labels "st3," and "srt," explicitly, with
/     "srt,  jmp .". This resolves the spot that was illegible at the
/     analogous "st3," label in the 4.0 scan: here st3 is simply a label
/     point that falls through to "srt, jmp .". No content is illegible.
/   - No assembler symbol table or pass-log appears in this scan. Unlike
/     4.0, this listing does NOT carry the game-saver / paper-tape loader
/     patch; instead pp.31-33 hold the separate starfield source ("stars
/     by prs for s/w 2b"), assembled at 6077/ with its own "start 4".
/ ----------------------------------------------------------------------
