/ Spacewar! 4.4 - normalised source transcription
/ ----------------------------------------------------------------------
/ Transcribed from the scanned listing "spacewar 4.4  5/17/63  ddp" (pt 1)
/ and "spacewar 4.4  5/21/63  ddp" (pt 2)
/ (spacewar-4.4-21may1963-(Morris).pdf), Monty Preonas's ("ddp") version,
/ the dual-console subjective-view ("Twin-Star") version in which alternate
/ frames are displayed on a second scope and each console sees its own ship
/ centred. Extracted by David M. Berry from the Joe Morris scan.
/
/ Method: verified page by page against the scan images, with the shared
/ routines cross-checked against the 4.0 and 4.2 listings and against the
/ masswerk reconstruction of this same version. Where the scan differs from
/ the reconstruction, the scan is followed. Conventions follow the
/ bitsavers Samson files: "~" marks a variable shown overlined in the
/ original; tabs separate label / instruction / "/" comment columns.
/
/ The dual-console machinery: a flag (sense flag 4) selects which console is
/ the "subjective" centre. The display dispatch goes through "db1"/"db2"
/ (set from dj5/dj6 per the flag) instead of a bare dpy, and through the
/ "kcb" relocation subroutine which subtracts the centred ship's coords so
/ that ship appears at scope centre. The dispt/starp/explosion display all
/ route through "jda kcb" + "xct db1" (or "xct db2"). This is the chief
/ structural difference from 4.2.
/
/ Provenance: the assembler pass-log that closes the scan (p.31) records
/   spacewar 4.4  5/17/63 ddp : pt 1   (pass 1 and 2)
/   spacewar 4.4  5/21/63 ddp : pt 2   (pass 1 and 2)
/   stars by prs  for s/w 2b           (pass 1 and 2)
/   spacewar 4.4 syms  5/23/63  jcm    (Joe C. Morris assembled the symbols)
/ The constants area runs 2736-3063. The background star data ("stars by
/ prs for s/w 2b") is a SEPARATE file in this assembly and is NOT printed in
/ this listing: pt 2 ends at "mtb," / "start 4" with no inline star table.
/
/ Confidence note: both parts are reasonably clear typewriter scans. A few
/ low-contrast spots on the late symbol-table pages were not needed (the
/ symbol table is not reproduced). Spots in the source that could not be
/ read with confidence are marked [?]; none were required in the end.
/ ----------------------------------------------------------------------
